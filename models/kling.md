# 可灵 Kling（1.6 / 2.0）分镜提示词规范

## 1. 核心参数与语法特征
- **语言偏好**：自然中文描述优于堆砌英文标签；主谓宾动作链条需清晰。
- **单镜时长**：5s（建议 1–2 个连贯动作）或 10s（建议“起因 → 动作转折 → 落幅”两段式）。
- **控制能力**：支持首帧图、首尾帧过渡、镜头运动预设（横移 / 推近 / 拉远 / 环绕 / 升降）与运动幅度（0.1–1.0）。

## 2. 七要素单镜头公式
`[风格核心] + [视觉基调（画幅/焦段）] + [色彩影调] + [景别与机位] + [构图落位] + [运镜路径] + [主体动作与物理环境反馈]`

## 3. 3 个可直接复用的实战分镜示例

### 示例 1：雨夜产品短片（5s · 首帧图驱动）
```text
写实商业产品短片，9:16 竖屏，35mm 定焦微距感；冷灰蓝雨夜街灯与暖橙橱窗反光交织；极低机位近景贴地仰拍；一只白色跑鞋位于画面下三分之一处；镜头以低速向右平移并轻微推近跟随鞋尖；白鞋踏入积水坑的瞬间，水花呈皇冠形向四周飞溅，鞋面防水涂层滑落水珠，背景霓虹倒影在涟漪中破碎又重组。
```

### 示例 2：科技感桌面开箱（5s · 推轨微距）
```text
极简工业设计广告，16:9 横屏，50mm 镜头浅景深；暗调钛灰桌面配单侧冷白轮廓光；俯拍 45 度中近景；银色金属耳机充电盒居中放置；镜头从中景缓慢匀速推近至特写；指尖轻推盒盖开启，内部绿色呼吸指示灯亮起，金属铰链反射出细腻高光。
```

### 示例 3：人物情绪转场（10s · 首尾帧衔接）
```text
电影感叙事短片，2.39:1 宽银幕，85mm 人像镜头；黄昏暖金色逆光与室内冷蓝阴影对比；中近景侧面跟拍；穿深灰风衣的青年站在落地窗前；前 5 秒镜头缓慢环绕至正面，人物低头看手机屏幕微光映亮眉眼；后 5 秒人物抬头望向窗外暮色，长舒一口气，窗外车流光斑在浅景深中化作柔美散景。
```
